# MCP Coding Agent

Autonomous coding agent exposed through Model Context Protocol (MCP).

## Stack

- Python 3.10+
- Official MCP Python SDK v2
- Streamable HTTP transport
- GitHub-ready repository structure

## Goal

Provide an MCP server that exposes safe, composable coding capabilities to an MCP host such as ChatGPT.

## Status

Phase 1: repository and MCP server skeleton.
